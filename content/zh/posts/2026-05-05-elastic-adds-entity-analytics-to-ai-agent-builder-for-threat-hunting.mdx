## 执行摘要

Elastic Security Labs 引入了 Conversational Entity Analytics，这是一个将实体分析数据直接集成到 Agent Builder 界面的功能。该功能提供了丰富的内联附件和 Canvas 预览，允许安全分析师在不离开聊天对话的情况下进行威胁狩猎。该功能旨在减少调查过程中的上下文切换。

## 技术分析

Conversational Entity Analytics 嵌入了 Elastic 所说的“实体分析功能”——可能是丰富的用户和主机上下文——作为 Agent Builder 对话中的内联内容。根据 Elastic Security Labs 的说法，该功能以“丰富的内联附件和 Canvas 预览”的形式提供这些内容，这意味着分析师可以在不打开单独的仪表板或查询单独的数据存储的情况下查看实体风险评分、资产关系和行为异常。

Agent Builder 是 Elastic 的低代码环境，用于创建驱动 AI 的安全代理，以自动化响应工作流程。通过添加内联实体上下文，该功能旨在加速之前需要在 Agent Builder 界面和主 Elastic Security 应用程序之间切换的分类和调查步骤。公告没有包括具体的性能基准或采用指标。

Elastic 没有透露这个功能是否在所有层级中都可用，或者是否需要特定的订阅级别。该公司的安全实验室定期发布开源工具和研究，但这次发布似乎是产品增强而不是新的独立工具。

## 缓解措施与建议

使用 Elastic Security 的安全团队应该评估 Conversational Entity Analytics 是否适合他们现有的调查工作流程。该功能可能通过在 Agent Builder 对话中保持实体数据可见，减少常见分类任务的平均响应时间。这次发布没有关联任何安全漏洞或配置错误风险；缓解部分包含在编辑结构中。
