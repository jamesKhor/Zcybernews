## Executive Summary

Unit 42 has tied a six-month intrusion set against government and state-affiliated Linux infrastructure to a cluster it tracks as **CL-UNK-1211**, with payloads that carry conversational, step-by-step reasoning comments characteristic of large language model output or an automated AI agent. The activity was observed between October 2025 and April 2026, according to the Palo Alto Networks threat intelligence team.

The operators deployed a mix of custom and open-source web shells, a cross-platform remote access trojan, and open-source utilities to maintain persistent access, dump databases, and exfiltrate government mailboxes — the last apparently to pivot into social media accounts tied to official email addresses. Unit 42 explicitly declines to attribute the cluster to either a nation-state or a criminal group, applying its `UNK` designation, so defenders should treat the campaign as an active, unattributed espionage operation rather than a known APT.

## Technical Analysis

Initial access centered on web shell deployment and credential harvesting against Linux servers. Unit 42 observed both custom shells and well-known open-source web shells pulled from GitHub, with interactive shell activity visible as child processes spawned from `php-fpm` in Cortex XDR telemetry.

For persistence, the attackers edited the `auto_prepend_file` directive across every PHP configuration file under `/etc/php/` and `/opt/plesk/php/`. Because `auto_prepend_file` causes a specified script to load before every PHP request, any file referenced there executes automatically — a durable, low-noise backdoor that survives reboots and blends into normal web traffic. Plesk's presence in the target path suggests the operators were aware of common hosting control panels on government web estates.

Beyond the shells, the toolkit included a custom cross-platform backdoor, open-source utilities, and a remote access trojan. The operators dumped entire database contents before exfiltrating them, and separately enumerated mailboxes to identify and reach social media accounts registered to government email addresses — a pivot pattern that turns an initial server compromise into downstream identity and communications access.

Defense evasion was methodical. Unit 42 reports attempts to disable endpoint protections on compromised hosts, tamper with system logs that would otherwise record the intrusion, and plant deceptive red-team markers — artifacts designed to make the activity look like a sanctioned security assessment rather than an intrusion.

The most distinctive finding is the code itself. Multiple PHP and shell scripts contained conversational annotations explaining the code's logic to the operator who issued the original instructions, rather than conventional developer documentation. Unit 42 lists three additional traits it associates with AI-operated attacks: section headers in scripts and shell commands (used by models to parse output), heavy use of Base64-encoded commands, and seamless shifts between PHP, JavaScript, Bash, and Python within a single operation. The report is careful to frame this as suggestive rather than conclusive — the artifacts are "consistent with" AI-assisted generation, not proof of an autonomous agent.

## Mitigations & Recommendations

Given the persistence mechanism, the highest-value detection is a configuration audit. Compare current `auto_prepend_file` values under `/etc/php/` and `/opt/plesk/php/` against a known-good baseline and treat any unexpected file reference as a potential backdoor. File integrity monitoring on those directories should alert on modification.

On the process side, defenders should baseline `php-fpm` child process behavior and hunt for shells spawning interactive commands, `curl`/`wget` fetches, or database client binaries. The Base64-heavy command pattern Unit 42 describes is a useful hunting pivot in process telemetry and shell history.

Because the operators attempted to disable endpoint protections and clear logs, tamper-detection alerts on EDR agents and gaps in system log continuity should be treated as intrusion indicators rather than operational noise. Mailbox enumeration tied to social media recovery flows warrants review of any government email account that shows unusual password-reset or account-recovery activity.

Unit 42 does not publish specific file hashes, IPs, or domains in the sections reviewed here, so signature-based blocking is not available from this report alone; behavior-based detection and configuration hygiene are the practical near-term controls.
