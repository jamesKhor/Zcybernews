## Stage 1 Acceptance Criteria

- Scheduled workflow runs 3 times daily instead of hourly.
- Scheduled workflow uses curate-only mode.
- During taste calibration, scheduled queues use a broader 8/6/6 daily shape: 8 candidates at 08:00 Asia/Shanghai, then 6 candidates at 16:00 and 6 candidates at 00:00. Reviewers may leave unclear candidates pending and only approve, deny, or comment on the items that clearly teach editorial taste.
- Curate-only mode writes review queue artifacts and does not generate MDX.
- Queue candidates include lane, score, source URLs, selection reasons, SEO brief, pending reviewer fields, taste rating placeholders, and structured why/why-not taste signals.
- Decision matrix includes selected candidates as `review-required`.
- Required pipeline dry run passes.
- Validation-only feed-health changes are not committed.

## Taste Calibration Targets

| Review gate | Target                                                             | Action                                                                                                                                                              |
| ----------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Day 0-1     | Founder reviews many candidates and approves only a few favorites. | Capture strong positive and negative examples with ratings and notes.                                                                                               |
| Day 3       | More selected candidates should match founder taste.               | Apply first selector taste-profile adjustment.                                                                                                                      |
| Day 7       | 70-80% of selected candidates rated `>=0.8`.                       | Tune lanes, sources, and reason weights from the review data.                                                                                                       |
| Day 10      | 80-90% of selected candidates rated `>=0.8`.                       | Suppress repeat low-rated patterns and review approved-generation readiness.                                                                                        |
| Day 14      | At least 90% of selected candidates rated `>=0.8`.                 | Routine manual review ends. If the target is met, return to normal autonomous publishing; if not, run autonomously with stricter caps/gates and daily sample audit. |

Autonomous publishing must return to review mode if the rolling 20-candidate liked ratio drops below 85%, average taste rating drops below 0.85, two auto-published articles are rejected in one day, GSC degrades materially, or a serious quality/attribution incident occurs.

Workflow note: scheduled runs default to curate-only during the calibration window. The workflow uses `AI_PIPELINE_CURATION_STARTED_ON` and `AI_PIPELINE_CURATION_MAX_DAYS` repository variables, defaulting to `2026-05-26` and `14`. While in curate-only calibration, scheduled caps default to `AI_PIPELINE_CALIBRATION_MORNING_QUEUE_MAX=8`, `AI_PIPELINE_CALIBRATION_AFTERNOON_QUEUE_MAX=6`, and `AI_PIPELINE_CALIBRATION_OVERNIGHT_QUEUE_MAX=6`, so the queue is broad enough to miss fewer hot stories while still allowing the founder to ignore unclear pending candidates. After Day 14, `AUTONOMY_GATE=true` lets `scripts/pipeline/autonomy-gate.ts` choose normal autonomous mode, strict autonomous mode, or a return to review mode. Set `AI_PIPELINE_AUTONOMY_APPROVED_BY` to `alex` or `eric` for normal mode; use `AI_PIPELINE_OPEN_REGRESSIONS`, `AI_PIPELINE_GSC_DEGRADED`, `AI_PIPELINE_SERIOUS_INCIDENT_OPEN`, or `AI_PIPELINE_REJECTIONS_TODAY` to force review mode when quality degrades.

Taste signal examples:

- Positive: `hot-topic`, `historical-exploitation`, `active-exploitation`, `reader-likely-cares`, `defender-actionable`, `strong-source`, `original-angle`, `seo-opportunity`, `brand-fit`.
- Negative: `generic-rewrite`, `weak-source`, `low-reader-value`, `too-speculative`, `too-vendor-pr`, `stale-topic`, `no-actionable-angle`, `overcovered`, `wrong-site-fit`.
